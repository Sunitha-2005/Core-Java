\# Fruit and Vegetable Billing System



\## Project Overview

The Fruit and Vegetable Billing System is a Java console-based application that helps users select fruits and vegetables, enter their choices, and calculate the total bill.



\## Features

\- Select fruits or vegetables.

\- Choose items using item codes.

\- Display the price of each selected item.

\- Add multiple items to the bill.

\- Calculate the total purchase amount.

\- Continue selecting items until the user chooses to stop.



\## Technologies Used

\- Java

\- Scanner class for user input

\- Switch statements

\- Do-while loops

\- Conditional statements



\## How to Run

1\. Open the project in Eclipse IDE.

2\. Locate `ProofofConcept.java` in the `com.LogicalStatements` package.

3\. Run the file as a Java Application.

4\. Follow the console prompts to select fruits or vegetables and calculate the bill.
